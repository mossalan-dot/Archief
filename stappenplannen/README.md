# Stappenplannen

Stap-voor-stap routes die een bezoeker volgt om voor een concrete
onderzoeksvraag bij de juiste bron uit te komen.

De volgorde is strikt: eerst zoekhulpen en indices, inventarissen secundair.
Eén bestand per onderzoeksvraag. Zie het sjabloon en de richtlijnen in
[`../CLAUDE.md`](../CLAUDE.md).
