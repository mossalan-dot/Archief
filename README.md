# Archief

Projecten voor archiefonderzoek.

## Projecten

- **[carnegie-heldenfonds](carnegie-heldenfonds/)** — interactieve kaart & statistiek van ~9.600 reddingsdossiers
  van het Carnegie Heldenfonds (Nationaal Archief 2.19.364), met AI uit de inventarisbeschrijvingen gestructureerd.
  Live: <https://grisburgh.nl/carnegie>

- **[engelandvaarders](engelandvaarders/)** — interactieve kaart & inzichten van ruim 2.100 Engelandvaarders
  (verzetsdeelnemers die 1940–1945 Engeland bereikten; index Engelandvaarders van het Nationaal Archief), met routes,
  herkomst-/bestemming-heatmaps en reisanimatie. Live: <https://engelandvaarders.alanmoss.nl>

- **[vermisten](vermisten/)** — doorzoekbare namenindex op de gedigitaliseerde-maar-niet-ge-OCR'de kaartenklapper
  van de Commissie tot het doen van Aangifte van Overlijden van Vermisten (VP-dossiers, Nationaal Archief 2.09.34.02),
  met per persoon een verwijzing naar het onderliggende dossier en inv.nr. Pijplijn + geverifieerde steekproef.
